# Presence

**Come as you are. Leave less alone.**

Simple web app for hosting and joining low-pressure, accepting local moments — coffee, walks, meals, game nights — with a clear culture of presence over performance and acceptance as the default.

## Live demo
https://presence-moments.vercel.app

## Core values
- Presence over performance
- Acceptance is the default
- Encouragement is welcome
- Come as you are

## Current MVP features
- Clear cultural charter on the home screen
- Host a Moment in under a minute (activity, time, place, vibes, charter agreement)
- Browse & filter Moments
- View details and request to join
- Local persistence of hosted moments (browser localStorage)
- Sample moments for Stockbridge / Conyers / Atlanta area

## Stack
Pure static HTML + CSS + vanilla JS. Deployed on Vercel.

## Next steps (planned)
- Real backend + accounts
- True geolocation / map view
- Host notifications + chat after acceptance
- Post-moment feedback for culture health
- Reputation based on showing up + acceptance signals
- Church / outreach "open table" mode

## Local development
Just open `index.html` or serve the folder with any static server.

```bash
npx serve .
```
